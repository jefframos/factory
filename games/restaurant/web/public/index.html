Shortcuts & help

Orbit: left drag · Pan: right drag · Zoom: wheel
Click to select · W / E / R: move / turn / size · F: focus
Delete: remove · D: duplicate · Ctrl+S: save · Ctrl+Z: undo · Esc: deselect

Cameras: select a station camera, 👁 Look through, orbit / pan / zoom until the gold frame (the game's 720 x 1080 screen) shows what you want, then 📸 Use this view. Save: the game reloads with it.

Walls: ✏️ Draw wall, then click corners (click the first one to close the loop; double-click or Enter ends an open wall). Select a wall to drag it whole, a gold corner to move it, or a green middle handle to add a corner there. Openings: 🪟 / 🚪 / ⬜ then click on a wall. Each opening is a cube that cuts the wall: select it, move it (a window up and down too) or size it (W / R).

Street: 🛣 Roads (B), then drag on the ground to lay road tiles (Shift+drag removes; the pieces fit themselves), and set how many cars drive them. 🌱 Lawn: click its corners. 🚶 People: an area people wander about in (move / size it, set how many).
