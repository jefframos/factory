Shortcuts & help

Orbit: left drag · Pan: right drag · Zoom: wheel
Click to select · W / E / R: move / turn / size · F: focus
Delete: remove · D: duplicate · Ctrl+S: save · Ctrl+Z: undo · Esc: deselect

Cameras: select a station camera, 👁 Look through, orbit / pan / zoom until the gold frame (the game's 720 x 1080 screen) shows what you want, then 📸 Use this view. Save: the game reloads with it.

Walls: select one to drag the whole wall, or a corner handle to move that corner. Openings (doors, windows, gaps) are rects in the inspector.
